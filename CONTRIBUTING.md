# Contributing and Submission Rules

## Student work

Use this repository as the course brief and template source. Create your own approved private project repository or workspace for your implementation and evidence.

Do not commit completed solutions, personal data, credentials, public target details, packet captures from unauthorised systems or instructor feedback to this repository.

## Documentation style

- Use clear headings and complete sentences.
- Redact personally identifiable information from screenshots.
- Name evidence consistently with your registration number, activity number and date.
- Explain what each piece of evidence proves.
- Cite external libraries, references and team contributions.

## Support requests

Use the issue template only for repository or practical-brief clarification. Never post credentials, internal IP addresses, actual captures, completed source code or reports in a public issue.
