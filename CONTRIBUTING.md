# Repository Use and Submission Rules

## Student work

This repository contains the course brief and the instructor-provided OT simulation source. Learners are expected to use the canonical source at `labs/ot-security/student-lab-source/`; a new implementation is not required. Do not execute the archival copy in `labs/ot-security/archive-original/`.

Submit your own analysis and evidence through a private learner/team repository or instructor-approved workspace. Do not commit learner submissions, private evidence, credentials, personal information or instructor feedback to this course-source repository. Cite the course source commit you used; do not claim its code as your own.

## Documentation and evidence style

- Use clear headings and complete sentences.
- Redact personally identifiable information from screenshots.
- Name evidence consistently with the learner/team ID, activity number and date.
- Explain what each piece of evidence demonstrates and how it supports the conclusion.
- Cite external libraries/references and declare any approved team contributions.
- Preserve the loopback-only configuration; source changes require instructor authorization.

## Support requests

Use the issue template only for repository or practical-brief clarification. Never post credentials, internal addresses, actual captures, private evidence, completed reports or sensitive source changes in a public issue.
