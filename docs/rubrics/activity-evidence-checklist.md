# Activity Evidence Checklist

Use this checklist before each submission.

- [ ] Correct course, activity, learner/team and date are visible.
- [ ] Work was completed only in the assigned isolated environment.
- [ ] The starting state and recovery action are recorded.
- [ ] Screenshots are legible and include relevant context.
- [ ] Packet/log evidence supports each technical conclusion.
- [ ] Sensitive values, credentials and unauthorised target details are removed.
- [ ] Source code and diagrams are original and committed in the learner/team repository.
- [ ] Evidence filenames are referenced in the report/evidence log.
- [ ] The final state is verified as safe and normal.
