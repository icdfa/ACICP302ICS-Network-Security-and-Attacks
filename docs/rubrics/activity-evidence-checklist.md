# Activity Evidence Checklist

Use this checklist before each activity submission.

- [ ] Correct course, activity, learner/team and date are identified.
- [ ] Work was completed only in the assigned isolated Ubuntu VM.
- [ ] The canonical `labs/ot-security/student-lab-source/` path and source commit are recorded.
- [ ] No files from `labs/ot-security/archive-original/` were executed.
- [ ] The source/configuration was confirmed to use loopback only; no bridged adapter or port forwarding was used.
- [ ] The starting state, exact authorized action, observed result and recovery action are recorded.
- [ ] Screenshots are legible and include relevant context; packet/log evidence supports technical conclusions.
- [ ] Evidence is the learner/team’s own and is stored only in the approved private workspace/repository.
- [ ] Course source is cited and not presented as learner-authored code.
- [ ] Sensitive values, credentials and unauthorized target details are removed.
- [ ] Evidence filenames are referenced from the evidence log/report.
- [ ] The lab processes were stopped and the final state was verified safe/normal.
