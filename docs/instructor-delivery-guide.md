# Instructor Delivery Guide

This guide supports delivery without exposing a completed solution.

## Before release

1. Confirm all learner VMs use approved isolated networking and clean snapshots.
2. Allocate each learner/team an authorised environment and evidence naming convention.
3. Publish activity deadlines and the E-Campus GitHub submission requirement.
4. Review the safety boundary at the start of every practical session.

## During delivery

- Demonstrate process concepts only; do not distribute completed implementation code.
- Verify scope cards before controlled validation activities.
- Assess reasoning, evidence quality, recovery and live defence—not only a working interface.
- Stop and investigate any report of unexpected connectivity or out-of-scope behaviour.

## After delivery

- Confirm every learner/team has restored the approved safe state.
- Retain required assessment evidence in the ICDFA-approved workflow.
- Keep marks, completed submissions and reference implementations out of this course repository.
