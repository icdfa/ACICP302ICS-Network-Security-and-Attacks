# Activity 03 — Packet Visibility and Protocol Analysis

## Purpose

Capture normal Modbus/TCP traffic and analyse it as evidence of how your testbed operates.

## Complete these tasks

1. Start only the normal process and monitoring components.
2. Capture traffic from the approved analyst VM or assigned capture point.
3. Isolate the relevant Modbus/TCP conversation in Wireshark.
4. Identify at least one request and its matching response.
5. Explain the source, destination, transaction relationship, function-code purpose, address/value meaning and observed result.
6. Save the capture using the required naming convention and reference it in the evidence log.

## Evidence to submit

- One labelled `.pcap` or `.pcapng` from your own isolated lab.
- Two annotated screenshots: one request and one matching response.
- Completed packet-analysis section in the lab report.
- A plain-language explanation of what the packets prove about normal operations.

## Success criteria

Your analysis links packet fields to the actual process state. A screenshot without an explanation, capture file and process context is not sufficient.
