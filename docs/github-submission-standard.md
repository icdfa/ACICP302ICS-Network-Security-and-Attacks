# GitHub Submission Standard

ICDFA practical submissions use GitHub. Submit the repository URL together with the final branch, commit reference and required file path through the ICDFA E-Campus activity.

## Your repository must include

- Course and activity name in the project README.
- Clear setup and safety instructions.
- Original source code/scripts where required.
- Topology, register map, evidence log, risk register and test plan.
- Evidence index linking claims to captures, logs and screenshots.
- Findings, references and recovery record.
- Meaningful commits that show the development process.

## Do not commit

- Credentials, tokens, keys or passwords.
- Real or unauthorised target details.
- Evidence obtained outside the authorised ICDFA simulation.
- Another learner’s work or instructor answer material.

## Final reference format

Provide the assessor with:

1. Repository URL.
2. Branch name.
3. Final commit ID.
4. Path to the final report and evidence index.
