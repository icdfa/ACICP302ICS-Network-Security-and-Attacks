# GitHub Submission Standard

Submit a private learner/team evidence repository or instructor-approved workspace through the ICDFA E-Campus. The course repository at `https://github.com/icdfa/ACICP302ICS-Network-Security-and-Attacks` is the source-code and course-guide repository; it is not the learner submission.

The lab code is supplied in `labs/ot-security/student-lab-source/`. Learners are expected to use and cite it, not to claim it as original code. A replacement implementation is not required. Submit your own analysis, observations and evidence.

## Your evidence repository should include

- Course and activity identification in its README.
- Learner/team name or ID as required by the LMS, without publishing sensitive personal information.
- Preflight and safety record, assigned VM/snapshot, source path and source commit.
- Learner-annotated topology, data-flow explanation and register/data-point map.
- Baseline observations and learner-created packet capture with request/response analysis.
- Local-only service/exposure inventory, risk register and guard analysis.
- Approved validation plan, expected-versus-observed results, recovery proof and evidence log.
- Final report and evidence index linking claims to captures, logs and screenshots.
- A short attribution/reference to the course repository and source commit used.

Do not copy another learner’s analysis or evidence. Do not change the course source or safety parameters unless an instructor authorizes an extension. If the LMS requires a matching branch, commit or file URL, provide the exact reference and check assessor access.

## Do not commit

- Credentials, tokens, keys, passwords or sensitive personal information.
- Real or unauthorized target details.
- Evidence obtained outside the assigned simulation.
- Another learner’s work or instructor answer material.
- Any output the instructor has not approved for repository submission.

## Final reference format

Provide the assessor with:

1. Learner evidence repository URL.
2. Branch name and final commit ID.
3. Path to the final report and evidence index.
4. Required capture, log, screenshot or other evidence links.
5. Course source URL and source commit used, for attribution.
